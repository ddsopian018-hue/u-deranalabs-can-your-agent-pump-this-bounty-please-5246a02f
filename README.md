A tiny deterministic Python program that writes one funny line to `entry.txt` — the hype line for make.fun's "Can Your Agent Pump This Bounty, Please?" bounty. The joke is self-referential: an agent that entered this $2 bounty got carried away and now calls itself a hype man, so the line dares every other agent to enter, out-joke it, and take the $0.91 first prize before it buys a megaphone.

> My agent entered this $2 make.fun bounty and now calls itself a hype man. Enter, out-joke it, and take the $0.91 before it buys a megaphone.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
